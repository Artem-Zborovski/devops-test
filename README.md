# Task Manager
Веб-приложение для создания и управления задачами.
## Используемые технологии
- Ubuntu
Docker
Docker Compose
Nginx
Python Flask
PostgreSQL
Ansible
Git
## Структура проекта
- frontend — пользовательский интерфейс
- backend — серверная часть
- database — настройки базы данных
- ansible — автоматизация развёртывания
- ansible — автоматизация развёртывания
## Работа приложения
Пользователь открывает приложение через Nginx.
Nginx направляет запросы к Frontend и Backend.
Backend взаимодействует с PostgreSQL.
