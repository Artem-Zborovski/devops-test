Меры безопасности

В проекте реализованы следующие базовые меры безопасности.

1. Межсетевой экран

Для управления входящими подключениями используется UFW.

Настроена политика:

Входящие подключения по умолчанию запрещены.

Исходящие подключения разрешены.

Для HTTP разрешён TCP-порт 80.

2. Защита конфигурационных данных

Пароль PostgreSQL хранится в файле .env.

Для .env установлены права доступа 600.

Файл .env добавлен в .gitignore и не публикуется в Git-репозитории.

3. Ограничение сетевого доступа

Nginx публикует порт 80.

Backend доступен только внутри Docker-сети.

PostgreSQL доступен только внутри Docker-сети.

Для взаимодействия контейнеров используется внутренняя сеть Docker Compose.

4. Хранение данных
Для PostgreSQL используется именованный Docker Volume db_data, позволяющий сохранять данные при перезапуске контейнеров.
